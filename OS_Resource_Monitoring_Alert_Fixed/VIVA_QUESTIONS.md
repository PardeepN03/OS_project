# Alert System Viva Notes

- The application compares sampled CPU, memory and disk percentages with user-defined limits.
- A warning is written when the measured value is equal to or greater than the threshold and alerts are enabled.
- The Check thresholds now button checks the latest sampled values immediately.
- A 60-second cooldown prevents duplicate warnings for the same resource.
- The application monitors and reports; it does not automatically terminate processes or repair performance issues.
